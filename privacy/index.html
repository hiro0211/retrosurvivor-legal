1はじめに・適用範囲

本プライバシーポリシー（以下「本ポリシー」）は、スマートフォン向けゲームアプリ「RetroSurvivor」（iOS 版・Android 版。以下「本アプリ」）で情報をどう扱うかを定めます。本アプリは個人開発者（以下「開発者」）が提供しています。

本アプリにはアカウント登録がなく、開発者はゲーム用のサーバーを持っていません。開発者が氏名、住所、電話番号などの入力を求めることはありません。

2扱う情報

2-1. 端末の中だけに保存する情報（外部に送りません）

  • ゲームの記録（スコア、進み具合、ゲーム内のコインや強化の状態）
  • アプリの設定（音量、言語など）

これらはお使いの端末の中にだけ保存します。開発者や第三者に送ることはありません。

2-2. 広告の配信のために Google が扱う情報

本アプリは Google の広告サービス「Google AdMob」（Google Mobile Ads SDK と、同意の管理に使う User Messaging Platform（UMP）SDK）で、バナー広告、インタースティシャル広告（画面全体の広告）、リワード広告（見るとゲーム内の報酬がもらえる広告）を表示します。広告の表示のために、次の情報が端末から Google に送られ、Google が扱います。

  • 広告 ID などの端末の識別子（iOS の IDFA は、App Tracking Transparency（ATT）で許可した場合だけ使われます。Android は広告 ID と App Set ID）
  • IP アドレス（おおよその地域の推定に使われることがあります）
  • 端末とアプリの情報（機種、OS とそのバージョン、言語、アプリ名とバージョンなど）
  • 広告の表示、タップ、動画の視聴などの操作の記録
  • 診断の情報（SDK の動作に関するクラッシュログやパフォーマンスのデータ）
  • 広告の同意の状態（同意の画面での選択。端末の中にも保存されます）

Google やその提携先は、広告の配信のために Cookie や、同じ働きをする識別子・端末内の保存領域を使うことがあります。Google がこれらの情報をどう使うかは、Google のサービスを使用するサイトやアプリから収集した情報の Google による使用をご覧ください。

2-3. お問い合わせのときにいただく情報

メールでお問い合わせいただいた場合は、メールアドレス、お名前（メールに含まれる場合）、お問い合わせの内容をお返事のために使います。

2-4. アプリ内課金（今後導入する場合）

今後、広告を消すためのアプリ内課金を追加する可能性があります。その場合、支払いは Apple（App Store）または Google（Google Play）が処理し、開発者はクレジットカードなどの支払い情報を受け取りません。導入する際は、扱う情報を本ポリシーに追記します。

2-5. 集めない情報

  • 氏名、住所、電話番号（お問い合わせで自分から書かれた場合を除く）
  • 連絡先、写真、カメラ、マイク、正確な位置情報（GPS）
  • 利用状況の分析ツールやクラッシュ報告ツールによる情報（現在、本アプリはこれらのツールを使っていません。使い始める場合は本ポリシーを改定します）

3情報の利用目的

  • ゲームを遊べるようにするため（記録と設定の保存）
  • 広告を表示し、リワード広告の報酬を渡すため
  • 広告の効果の測定と、不正なクリックや表示の防止のため（Google が行います）
  • 同意の画面での選択を守るため
  • お問い合わせにお返事するため

5広告の同意と、同意の変更・取り消し

本アプリは Google の UMP SDK を使い、お住まいの地域の法令に合わせて同意の画面を表示します。

  • EEA・英国・スイス: 初回の起動時に、Cookie などの保存と、広告のための情報の利用について同意を求めます。同意しなくても、本アプリは遊べます。その場合、Google はパーソナライズされていない広告や、配信の方法を限った広告を表示します。
  • iOS: 広告のトラッキングについて、Apple の ATT の画面で許可を求めます（その前に説明の画面を出すことがあります）。許可しない場合、IDFA は使われません。許可しなくても、本アプリの機能は変わりません。
  • 米国の一部の州: 広告のための個人情報の「販売」または「共有」をやめるよう求めることができます（オプトアウト）。

同意を変える・取り消す方法

  • 本アプリの設定画面にある「プライバシー設定」から、同意の画面をもう一度開いて選び直せます。このボタンは、法令で必要な地域でだけ表示されます。
  • iOS のトラッキングの許可は、iPhone の「設定」→「プライバシーとセキュリティ」→「トラッキング」でいつでも変えられます。
  • Android の広告 ID は、端末の設定（多くの機種で「設定」→「Google」→「広告」、または「設定」→「プライバシー」→「広告」）からリセット・削除できます。メニューの名前は機種によって違います。

手順の詳しい説明はサポートのページにあります。

6EEA・英国・スイスにお住まいの方（GDPR）

欧州経済領域（EEA）、英国、スイスにお住まいの方には、EU 一般データ保護規則（GDPR）またはこれに相当する法令が適用されます。開発者は Google の EU ユーザーの同意ポリシーに従い、必要な同意を求めます。

6-1. 処理の法的根拠

  • Cookie などの保存と、パーソナライズ広告のための処理: 同意（GDPR 6条1項a）
  • パーソナライズされていない広告の配信、広告の測定、不正の防止: 正当な利益（GDPR 6条1項f）。必要な場合は同意によります。
  • お問い合わせへのお返事: 正当な利益（GDPR 6条1項f）

6-2. あなたの権利

あなたには、アクセス、訂正、削除、処理の制限、データポータビリティ、処理への異議を求める権利と、同意をいつでも取り消す権利があります。同意を取り消しても、それまでの処理の適法性は変わりません。権利を使いたい場合は、お問い合わせ先までご連絡ください。お住まいの国のデータ保護の監督機関に苦情を申し立てることもできます。

なお、開発者は広告の情報を自分では持っていません。広告に関する情報は Google が管理しています。Google が持つ情報については、Google プライバシーポリシーの手順でも権利を行使できます。

7米国の州法（CCPA / CPRA など）

カリフォルニア州など、プライバシー法のある米国の州にお住まいの方向けの説明です。

  • 扱う情報の種類: 識別子（広告 ID、IP アドレス）、インターネットなどの利用の記録（広告の操作）、IP アドレスから推定されるおおよその位置、端末の情報。くわしくは2 章をご覧ください。
  • 広告 ID などを Google の広告のために使うことは、州法でいう個人情報の「共有」（行動ターゲティング広告のための共有）や「販売」に当たる場合があります。開発者がお金と引き換えに個人情報を売ることはしていません。
  • オプトアウトの方法: 本アプリの設定画面の「プライバシー設定」から「Do Not Sell or Share My Personal Information（個人情報を販売・共有しない）」を選べます。選んだ内容は Google に伝えられ、Google は配信を制限します。
  • あなたには、扱われている情報を知る権利、削除・訂正を求める権利、権利を使ったことで不利な扱いを受けない権利があります。お問い合わせ先までご連絡ください。

8子どものプライバシー（年齢）

本アプリは13歳未満の子どもを対象としていません（EEA などでは、各国で同意できる年齢に満たない方を対象としていません）。開発者は、13歳未満の子どもから知りながら個人情報を集めることはしません。13歳未満の子どもの情報を意図せず受け取ったと分かった場合は、すぐに削除します。お心当たりのある場合はお問い合わせ先までご連絡ください。

9保管期間と削除の方法

  • ゲームの記録と設定: 端末の中にだけあります。本アプリを削除（アンインストール）すると、すべて消えます。開発者の手元にはないため、開発者は復元も削除もできません。
  • 広告の同意の状態: 端末の中に保存されます。本アプリを削除すると消え、次に入れたときにもう一度確認します。
  • Google が扱う広告の情報: Google のポリシーに従って保管されます。Google のデータ保持をご覧ください。広告 ID をリセットすると、それまでの ID とのつながりを切れます。
  • お問い合わせのメール: お返事に必要な期間だけ保管し、不要になったら削除します。削除を希望する場合は、お問い合わせ先までご連絡ください。

10安全管理

  • 開発者はゲーム用のサーバーを持たず、ゲームの記録を集めていません。
  • Google Mobile Ads SDK の通信は、暗号化された通信（TLS）で行われます。
  • お問い合わせのメールは、開発者だけが読めるメールアカウントで管理します。

11国外での取り扱い

Google などの第三者サービスを使うため、情報は米国など日本の外にあるデータセンターで扱われることがあります。各社は、標準契約条項などで保護の措置をとっています。

12本ポリシーの改定

法令の変更や機能の追加（アプリ内課金や分析ツールの導入など）に合わせて、本ポリシーを改定することがあります。改定したときは、このページの最終更新日を変えてお知らせします。大きな変更があるときは、本アプリの中でもお知らせします。
